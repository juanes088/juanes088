## Proyectos

**[VoxVision](https://github.com/juanes088/VoxVision)**  
Un asistente de voz que además ve por la cámara: le hablas, le muestras algo y te responde.
Combina voz a texto con Whisper, un modelo de visión y voz sintética con Piper.

**[Teclado Virtual](https://github.com/juanes088/Teclado-Virtual)**  
Un teclado que se usa con gestos de la mano frente a la cámara. Detecta los dedos con
MediaPipe y "haces clic" pellizcando con el pulgar y el índice.

**[ROBERTO](https://github.com/juanes088/Agente-AI)**  
Un asistente de voz que abre y controla Chrome por ti, y cuando quieres, conversa usando
IA generativa.

**[Rentabilidad inmobiliaria en Medellín](https://github.com/juanes088/Fundamentos-ML-Platzi)**  
Un proyecto de machine learning para analizar y predecir precios de vivienda, usando
regresión, K-means y PCA.

**[Blog personal](https://juanes088.github.io/Page---Actividad-universitaria/)**  
Un sitio sencillo hecho a mano con HTML, CSS y JavaScript, con un diseño minimalista.
